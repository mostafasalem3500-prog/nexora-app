# الهوية البصرية وDesign Tokens — NEXORA TECH

## خطة التصميم (قبل البناء)

**اللون** — 6 قيم أساسية:
- `--bg-deep` #0E1420 — كحلي فحمي عميق (وليس أسود مطلق #0B0B0B المستهلك)
- `--bg-warm` #F2EFE6 — بديل دافئ عن الأبيض الصارخ لأقسام الوضع الفاتح
- `--brand-blue` #2A5CFF — أزرق كهربائي، اللون التعريفي الرئيسي
- `--brand-teal` #16C9B8 — فيروزي رقمي، للتفاعل والبيانات الحية
- `--accent-violet` #7C5CFF — بنفسجي، **محدود جدًا**: توهج/تدرجات فقط، لا تعبئات كبيرة
- `--ink` #E7ECF5 (نص على الداكن) / `--ink-dark` #131A28 (نص على الفاتح)

**الخط** — عائلتان مختلفتان بوضوح:
- **IBM Plex Sans Arabic** — العناوين والنصوص العربية (طابع تقني/هندسي يناسب شركة أنظمة، وليس خطًا تجاريًا ناعمًا)
- **Manrope** — الأرقام، التسميات الإنجليزية المدمجة، وواجهات الأجهزة داخل الـMockups (هندسي، متمايز بوضوح عن IBM Plex)

**التخطيط** — Editorial غير متماثل، ليس شبكة بطاقات موحدة:
```
[ Hero: نص 45% | مشهد أجهزة حي 55%، غير متمركز ]
[ شريط قدرات: خط أفقي رفيع + 6 عناصر نصية، بلا أيقونات كبيرة ]
[ معرض الحلول: مخطط شبكي أفقي (Sales→CRM→ERP→...) بعقد متصلة بخطوط بيانات ]
[ الخدمات: بطاقة كبيرة واحدة + 4 بطاقات أصغر بجانبها، ليست شبكة 3×3 متطابقة ]
[ الأعمال: شبكة غير متساوية الأحجام (Masonry خفيف) ]
```
المحاذاة: البداية (start) للنصوص الطويلة، ومركزية فقط للعناصر الاحتفالية (CTA السينمائي).

**المبادئ**:
1. لا بطاقات SaaS متطابقة الظل والزوايا — نصف قطر متفاوت حسب حجم العنصر (كبير=12px، صغير=8px، الأزرار=6px).
2. الحركة تخدم الفهم فقط: خط بيانات يتحرك بين العقد لأنه *يشرح تدفق النظام*، وليس فقط "fade-up" عشوائي.
3. عنصر الجرأة الوحيد: مشهد الأجهزة الحي في الـHero. كل ما حوله هادئ ومنضبط.
4. تجنب: eyebrow labels بأحرف كبيرة، الفواصل بنقاط وسطى (·)، أسهم "→" ملحقة بكل زر.

## مراجعة الخطة

- الخلفية الداكنة + الأزرق الكهربائي ليست التوليفة الافتراضية الشائعة (كريمي+تراكوتا أو أسود+نيون حاد) — مطابقة لطلب العميل صراحة (كحلي فحمي، أزرق، فيروزي، بنفسجي محدود).
- استخدمنا خطين مختلفين فعليًا (IBM Plex Sans Arabic / Manrope) بدل الاكتفاء بخط واحد.
- لا نستخدم عدادات "01/02/03" إلا في قسم "رحلة تنفيذ المشروع" لأنه تسلسل زمني فعلي (6 مراحل)، وليس ديكورًا.

## Design Tokens (CSS Variables)

```css
:root {
  /* ألوان */
  --bg-deep: #0E1420;
  --bg-deep-2: #121A2B;      /* طبقة أعلى قليلًا للبطاقات على الخلفية الداكنة */
  --bg-warm: #F2EFE6;
  --bg-warm-2: #EAE6D9;
  --brand-blue: #2A5CFF;
  --brand-blue-dim: #1E3E99;
  --brand-teal: #16C9B8;
  --accent-violet: #7C5CFF;
  --ink: #E7ECF5;
  --ink-muted: #9AA7C2;
  --ink-dark: #131A28;
  --ink-dark-muted: #5B6472;
  --success: #2FD07A;
  --warning: #F0B429;
  --danger: #FF5C6C;

  /* خطوط */
  --font-ar: "IBM Plex Sans Arabic", "Tahoma", sans-serif;
  --font-en: "Manrope", "Segoe UI", sans-serif;

  /* مقياس النوع (Arabic +12% عن اللاتيني) */
  --text-xs: 0.8125rem;
  --text-sm: 0.9375rem;
  --text-base: 1.0625rem;   /* 17px بدل 16px */
  --text-lg: 1.25rem;
  --text-xl: 1.75rem;
  --text-2xl: 2.5rem;
  --text-3xl: 3.5rem;
  --leading-body: 1.8;
  --leading-heading: 1.45;

  /* مسافات */
  --space-1: 0.5rem;
  --space-2: 1rem;
  --space-3: 1.5rem;
  --space-4: 2.5rem;
  --space-5: 4rem;
  --space-6: 6.5rem;

  /* أنصاف أقطار متفاوتة حسب الحجم */
  --radius-sm: 6px;   /* أزرار وحقول */
  --radius-md: 10px;  /* بطاقات صغيرة */
  --radius-lg: 16px;  /* لوحات وأقسام كبيرة */

  /* ظلال ناعمة */
  --shadow-soft: 0 8px 30px rgba(10, 15, 30, 0.25);
  --shadow-glow-blue: 0 0 40px rgba(42, 92, 255, 0.25);
  --shadow-glow-teal: 0 0 40px rgba(22, 201, 184, 0.20);

  /* حركة */
  --ease-standard: cubic-bezier(.4,0,.2,1);
  --duration-fast: 150ms;
  --duration-base: 300ms;
  --duration-slow: 600ms;
}
```

كل هذه القيم تُخزَّن فعليًا في جدول `SiteSettings.theme` وتُحقن كـ CSS variables عند البناء، حتى يقدر مدير النظام من لوحة التحكم تغيير أي لون/خط دون لمس الكود.
